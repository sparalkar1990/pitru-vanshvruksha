# पितृ वंशवृक्ष — GitHub Pages

Deploy the contents of this folder to the repository:
https://github.com/sparalkar1990/pitru-vanshvruksha

## GitHub Pages
1. Upload `index.html`, `manifest.webmanifest`, `sw.js`, and the `icons` folder to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Open:
   `https://sparalkar1990.github.io/pitru-vanshvruksha/`

## Included
- Latest verified lineage app HTML.
- Marathi / Hindi / English UI switching.
- English name localization for the current dataset.
- Add / edit / delete / reset data.
- Category and source filters.
- Search and local browser storage.
- PWA manifest and service worker support files.
